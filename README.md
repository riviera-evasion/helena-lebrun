# Riviera Évasion

Magazine de voyage francophone : inspirations, destinations et conseils pour s'évader depuis Nice et la Côte d'Azur.

## Stack
- Next.js App Router / React / TypeScript
- Tailwind CSS 4
- Cloudflare Workers via OpenNext

## Développement
```bash
npm install
npm run dev
```

## Cloudflare
```bash
npx wrangler login
npm run cf:build
npm run preview
npm run deploy
```

Le déploiement nécessite une connexion au compte Cloudflare et la configuration du domaine. Aucun secret ne doit être commité dans Git.
